## Requesting licensing information

```
POST https://collections.mp.microsoft.com/v7.0/beneficiaries/me/keys HTTP/1.1
Accept-Encoding: gzip, deflate
MS-CV: <CV>
User-Agent: XboxGameRuntime
Authorization: WLID1.0=t=<token>
Content-Length: 1733
Content-Type: application/json; charset=UTF-8
Host: collections.mp.microsoft.com
Connection: Keep-Alive
Cache-Control: no-cache

{"serviceTicket":"<JWTToken>","publisherUserId":""}
```

Microsoft Store API endpoint, will check if you're able to request licensing information for a specific product. The serviceTicket is a JWT token that is generated by the Xbox Game Runtime. It contains information about the user and the application that is requesting the key. The publisherUserId is an optional field that can be used to specify the user ID of the publisher.

## License gathering

https://learn.microsoft.com/en-us/gaming/gdk/docs/store/commerce/pc-specific-considerations/xstore-license-tokens

```
POST https://licensing.mp.microsoft.com/v8.0/licenseToken HTTP/1.1
Accept-Encoding: gzip, deflate
MS-CV: useless m8
User-Agent: XboxGameRuntime
Authorization: t=<token>
Content-Length: 2010
Content-Type: application/json; charset=UTF-8
Host: licensing.mp.microsoft.com
Connection: Keep-Alive
Cache-Control: no-cache

{"parentProductId":"<parentProductId>","enforceSellableBy":true,"relatedProductIds":"[<this will be filled with related product IDs, if the parent product ID is a bundle>]","customDeveloperString":"<customDeveloperString>","beneficiaries":[{"identityValue":"t=<token>","localTicketReference":"<reference>","identityType":"Msa"}]}
```

which will answer

```JSON
{
    "licenseToken": "<JWTToken>"
}
```

Data Structure

```
the header is 

{
  "alg": "RS256",
  "kid": "2F9DAFA5EDE2B04E4A4F8D5C5AED29157171B303", <- technically shouldn't change
  "x5t": "<sounds generated>",
  "typ": "JWT"
}

the body is 

{
  "LicenseTokenClaim": "<base64>",
  "nbf": <time issued, timestamp>,
  "exp": <expiration, timestamp>,
  "iss": "LicensingFD",
  "aud": "SDK/ISV"
}
```

LicenseTokenClaim is a base64 encoded JSON object that contains the following fields:

```JSON
{"certificateId":"<certId>","customDeveloperString":"<customDeveloperString>","licensableProducts":[<list of licensable products>],"payload":"<hashedpayload>","tokenVersion":1}
```

The licensableProducts is a list of all products that are part of the package, including the parent product and any related products. The payload is a hashed value that represents the license information for the package.

```JSON
{"endDate":"9999-12-31T23:59:59.9999999+00:00","isShared":false,"id":"<user-product entitlement Id>","productId":"<productId>","skuId":"0010","userId":"<hashed format of UserID>"}
```
